# Jain Desi & Pure (Jain Food & Co)

A premium, artisanal e-commerce web storefront for **Jain Desi & Pure** — specializing in 100% natural, traditionally crafted cold-pressed oils, stone-ground flours (attas), and hand-pounded spices.

## ✨ Features

- **Modern Aesthetic & UI**: Handcrafted responsive design with rich typography, earth-tone aesthetics, and smooth animations.
- **Product Catalog & Filtering**: Seamless category browsing for cold-pressed oils, traditional stone-ground flours, and pure spices.
- **Interactive Cart & Checkout Flow**: Full cart drawer, quantity controls, address capture, payment options (COD & UPI), and order confirmation.
- **Farmer Stories & Transparency**: Authentic sourcing stories and lab-certified purity details.
- **Fast Performance**: Built with React 19 and Vite for instant load times and snappy transitions.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/RITESHKUMAR7488/JainFoodAndCo.git
   cd JainFoodAndCo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **Vanilla CSS / Modern Design Tokens**
